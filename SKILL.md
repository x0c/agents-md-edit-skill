# AGENTS.md Edit

Improve the decisions future agents make. Preserve behavior, scope, exceptions and discoverability; brevity alone is not success. Explicitly read-only reviews never write files.

## A bounded change

1. Identify the requested decision, its existing authority and overlapping rules. Read that domain and relevant links; do not turn a one-line requirement into a complete policy suite.
2. Update one authoritative home. Reconcile conflicts using current user intent and evidence. Change generated text through its maintenance source. Do not promote a temporary example, frustration or runtime instruction into permanent policy.
3. Describe document contents in navigation. Requirements must be discoverable before ordinary implementation without the user naming their keywords. Keep the shared relevance instruction; remove stale trigger catalogs and reading quotas within the authorized scope.
4. Re-read the affected domain and references. Compare the resulting action on an ordinary task, an exception and an unrelated task. Compression may remove words, never applicability, timing or adopted constraints.

## A whole-file review or cleanup

Read [decision criteria](references/decision-criteria.md). Read the full file and design its structure around decision ownership rather than inherited headings. Inventory every domain's issues and assign retain, merge, move, route, remove or unresolved dispositions. Verify the destination of moved material; do not leave the lower body outside the review.

For a review, report concrete issues and representative revised wording. For cleanup, integrate the changes and check every retained behavior's home, reachability and applicable exceptions. Compare measured default-loaded size before/after (token figures are estimates); explain justified growth without treating a target as the criterion.

## Structural checks

Run `python3 scripts/audit.py PATH --json` from this skill directory, or use its absolute script path. Read [audit coverage](references/audit.md) when interpreting the report. Inspect coverage before findings: zero identified index sections or links does not establish valid navigation. A clean report does not prove semantics or execution quality.
